What it is

A complete CRM, not a SaaS

wacrm is a template — you fork it, host it, and own everything: the code, database (Supabase), and domain. No seat pricing, no lock-in.

📥 Inbox + pipeline

Shared inbox using the official WhatsApp Business API (multiple agents on one number) with Kanban sales pipelines linked to conversations.

🤖 AI + automations

No-code automations (triggers, conditions, webhooks) and an AI assistant (your own OpenAI/Anthropic key) that responds based on your own knowledge base.

🔌 API + MCP

Public REST API with revocable keys, plus an MCP server to control the CRM directly from Claude, Cursor, and other AI assistants.

How it works

From fork to live CRM

The recommended workflow is fork → configure credentials → deploy — no infrastructure of your own to maintain.

Fork on GitHub→ Supabase (Postgres + Auth)→ WhatsApp Business API (Meta)→ Deploy (Hostinger or Node.js)→ Inbox + pipeline live
Prerequisites

What to have before you start

Stack: Next.js 16 (App Router), React 19, TypeScript, Tailwind v4, Supabase, and the Meta Cloud API.

Node.js + npm

To run locally and install dependencies.

# check version
node -v

Supabase project

Postgres + Auth + Storage + RLS. You create your own and enter the keys in .env.local.

# main variables
NEXT_PUBLIC_SUPABASE_URL
NEXT_PUBLIC_SUPABASE_ANON_KEY
SUPABASE_SERVICE_ROLE_KEY

WhatsApp Business API

Meta app with Cloud API configured, plus a 64-character encryption key for tokens.

# variables
META_APP_SECRET
ENCRYPTION_KEY
User guide · step by step

From fork to running dashboard

Real steps to get your own instance running in development.

1

Fork and clone

Fork this repo on GitHub and clone your fork.

git clone https://github.com/<seu-usuario>/wacrm.git  # your fork
cd wacrm
2

Install the dependencies

Standard installation via npm.

npm install
3

Set up the environment

Copy the example and fill in your Supabase and Meta credentials.

cp .env.local.example .env.local  # edit with your keys
4

Run in development

Starts the local server — you'll be redirected to /login (or /dashboard if you're already authenticated).

npm run dev  # http://localhost:3000
5

Check types, lint, and tests

The same commands that run in the project's CI.

npm run typecheck
npm run lint
npm run test
6

Deploy

Recommended: Hostinger (managed Node.js, connects to the fork and builds on push to main). But it runs anywhere with Node.js — Vercel, Railway, your own VPS.
