Qué es

Un CRM completo, no un SaaS

wacrm es una plantilla — haces un fork, la alojas y eres dueño de todo: el código, la base de datos (Supabase) y el dominio. Sin precios por usuario ni dependencia del proveedor.

📥 Bandeja de entrada + pipeline

Inbox compartida en la WhatsApp Business API oficial (varios agentes en un solo número) con pipelines de ventas en Kanban vinculados a las conversaciones.

🤖 IA + automatizaciones

Automatizaciones no-code (disparadores, condiciones, webhooks) y un asistente de IA (tu propia clave de OpenAI/Anthropic) que responde con base en una base de conocimientos propia.

🔌 API + MCP

API REST pública con claves revocables, más un servidor MCP para controlar el CRM directamente desde Claude, Cursor y otros asistentes de IA.

Cómo funciona

Del fork al CRM en línea

El flujo recomendado es fork → configurar credenciales → deploy, sin infraestructura propia que mantener.

Fork en GitHub→ Supabase (Postgres + Auth)→ WhatsApp Business API (Meta)→ Deploy (Hostinger o Node.js)→ Inbox + pipeline en línea
Requisitos previos

Qué necesitas antes de empezar

Stack: Next.js 16 (App Router), React 19, TypeScript, Tailwind v4, Supabase y Meta Cloud API.

Node.js + npm

Para ejecutarlo localmente e instalar dependencias.

# comprobar versión
node -v

Proyecto de Supabase

Postgres + Auth + Storage + RLS. Creas el tuyo y completas las claves en el .env.local.

# variables principales
NEXT_PUBLIC_SUPABASE_URL
NEXT_PUBLIC_SUPABASE_ANON_KEY
SUPABASE_SERVICE_ROLE_KEY

WhatsApp Business API

App Meta con Cloud API configurada, más una clave de cifrado de 64 caracteres para los tokens.

# variables
META_APP_SECRET
ENCRYPTION_KEY
Guía de uso · paso a paso

Del fork al dashboard en funcionamiento

Pasos reales para poner en marcha tu propia instancia en desarrollo.

1

Fork y clona

Haz fork de este repo en GitHub y clona tu fork.

git clone https://github.com/<seu-usuario>/wacrm.git  # tu fork
cd wacrm
2

Instala las dependencias

Instalación estándar mediante npm.

npm install
3

Configura el entorno

Copia el ejemplo y completa las credenciales de Supabase y Meta.

cp .env.local.example .env.local  # edita con tus claves
4

Ejecútalo en desarrollo

Inicia el servidor local — se te redirigirá a /login (o /dashboard si ya iniciaste sesión).

npm run dev  # http://localhost:3000
5

Verifica los tipos, el lint y las pruebas

Los mismos comandos que se ejecutan en la CI del proyecto.

npm run typecheck
npm run lint
npm run test
6

Deploy

Recomendado: Hostinger (Node.js administrado, conecta el fork y hace build al hacer push a main). Pero funciona en cualquier lugar con Node.js: Vercel, Railway, VPS propio.
